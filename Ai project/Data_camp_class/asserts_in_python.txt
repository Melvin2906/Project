unitest in python
in python to do unitest we use classes and define the unitest fonction in the classes
we have:
    - .assertEqual() and .assertNotEqual()
    - .assertIs() and .assertIsNone()
    - .assertTrue() and .assertFalse()
    - .assertIsInstance() and .assertIn()
    - .assertRaises()

Run unittest:
python3 -m unittest 'file name'
python3 -m unittest -k "SomeStringOrPattern" 'file name' (like the -k of the pytest framework)
python3 -m unittest -f 'file name' (fail fast flag)
python3 -m unittest -c 'file name' (catch flag)
python3 -m unittest -v 'file name' (verbose flag)
